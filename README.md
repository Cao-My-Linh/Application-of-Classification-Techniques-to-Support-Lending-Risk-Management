# Application of Classification Techniques to Support Lending Risk Management

## Overview
This project applies different classification models to predict loan default risk.  
The goal is to support credit risk management in lending institutions.

## Dataset
- Source: public dataset 
- Features: Borrower profile, loan amount, repayment status, etc.

## Methods
- Logistic Regression
- Decision Tree
- Random Forest

## Results
- Random Forest: 72% accuracy

## Tools
Python, Pandas, Scikit-learn, Matplotlib
